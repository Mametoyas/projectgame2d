
## 📖 เนื้อเรื่อง (Storyline)
อาณาจักรถูกกองทัพมอนสเตอร์บุกโจมตี  
ผู้เล่นจะต้องวางแผนป้องกัน โดยสร้างหอคอย (Towers) และอัปเกรดอาวุธ  
เพื่อหยุดยั้งศัตรูไม่ให้บุกทะลวงไปถึง "ปราสาทหลัก"  

---

## 🕹️ แนวเกมและฟีเจอร์ (Gameplay & Features)
- เกมแนว **Tower Defense 2D**  
- ผู้เล่นสามารถสร้าง **หอคอย** เพื่อป้องกันเส้นทาง  
- ศัตรูหลายประเภท (มอนสเตอร์, บอส, ยูนิตพิเศษ)  
- ระบบ **อัปเกรดหอคอย** (เพิ่มพลังโจมตี / ความเร็ว / ระยะยิง)  
- แผนที่หลายด่าน ความยากเพิ่มขึ้นเรื่อยๆ  
- ระบบ **คะแนนและเงินในเกม** สำหรับซื้อหอคอย  

---

## 🎮 วิธีการเล่น (Controls)
- 🖱️ คลิกซ้าย : วางหอคอย  
- 🖱️ คลิกขวา : ยกเลิก/ลบหอคอย  
- ⏩ ปุ่ม Space : เร่งความเร็วของเกม  
- ⏸️ ปุ่ม Esc : หยุดเกม / เมนู
