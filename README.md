## 📖 เนื้อเรื่อง (Storyline)
     การต่อสู้แย่งชิงดินแดน เกิดขึ้นมานานแล้ว ตั้งแต่อดีตกาล เหล่า  ปีศาจพยายามจะขยายขอบเขตการปกครองของพวกมันออกไปให้ไกลที่สุด เพื่อขยายแหล่งที่อยู่ และทำลายทุกอาณาจักรที่มัน ย่างกราย     ผ่านไป ในทุกอาณาจักรที่พวกมันได้เดินทางผ่านเพื่อขยายขอบเขตนั้น จำต้องล่มสลายลงอย่างหลีกเลี่ยงไม่ได้ จนปัจจุบันนี้ มันได้มาถึงอารา จักรของเราแล้ว ถึงเวลาที่ต้องลุกขึ้นสู้ เพื่อปกป้องและโต้กลับการมา  ถึงของพวกมัน จงคุ้มกันบ้านของท่าน ทำลายศัตรูท่าน และกอบกู้ดิน  แดนของท่านที่เสียไป!!!

## 🕹️ แนวเกมและฟีเจอร์ (Gameplay & Features)
- เกมแนว **Tower Defense 2D**  
- ผู้เล่นสามารถสร้าง **หอคอย** เพื่อป้องกันเส้นทาง  
- ศัตรูหลายประเภท (มอนสเตอร์, บอส, ยูนิตพิเศษ)  
- ระบบ **อัปเกรดหอคอย** (เพิ่มพลังโจมตี / ความเร็ว / ระยะยิง)  
- แผนที่หลายด่าน ความยากเพิ่มขึ้นเรื่อยๆ  
- ระบบ **คะแนนและเงินในเกม** สำหรับซื้อหอคอย  

---

## 🎮 วิธีการเล่น (Controls)
- 🖱️ คลิกซ้าย : เลือกป้อมปราการ/ตำแหน่ง 
- 🖱️ คลิกซ้าย-->ขวา : ยกเลิก/ลบหอคอย  
- 🖱️ คลิกซ้าย-->ซ้าย : อัพเกรดหอคอยที่เลือก
- ⏩ ปุ่ม Space : เร่งความเร็วของเกม  
- ⏸️ ปุ่ม Esc : หยุดเกม / เมนู
